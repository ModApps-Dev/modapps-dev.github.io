Permission first

The dashboard does not become a security shortcut.

Business data is queried under the current viewer's Odoo environment. ACLs, record rules, field groups, allowed companies, language and timezone remain in force for results, drill-through, previews and exports.

  • No arbitrary SQL, Python, safe_eval, JavaScript or browser-supplied domains
  • Saved definitions are validated on the server before sharing
  • Cache entries are isolated by user and access context
  • Exports rerun fresh queries instead of trusting rendered data
  • Scheduled reports fail closed if the saved execution user loses access
  • Viewer, Designer and Manager roles are separated
